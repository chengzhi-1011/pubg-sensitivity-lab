    Method / Boundaries

    数值口径与使用边界

    这是一套个人起点生成器，不是“无后坐力”脚本。枪械、配件、FOV 与拉枪节奏仍需在 PUBG 训练场复核。

    推荐逻辑

    先按手腕 / 混合 / 手臂建立约 30 / 40 / 50 cm/360 起点，作战偏好再做 ±5 cm 调整； 与你当前手感按 65% / 35% 融合。三项屏幕测试只做最高 ±6% 微调，再受鼠标垫宽度约束，最后反算并校验游戏 1—100 刻度。

    当前字段

    输出覆盖 PC 版常规、垂直增强、Aim、ADS，以及 2x / 3x / 4x / 6x / 8x / 15x。 灵敏度按整数 1—100 输出，垂直增强按 0.50—2.00 的游戏范围输出。

    非线性换算

    PUBG 灵敏度并非线性刻度。本页采用社区长期使用的近似： yaw ≈ 0.00005555 × FOV × 10^(sens / 50)，因此灵敏度增加约 15，速度约翻倍。

    浏览器边界

    免点击测试读取的是屏幕光标与 CSS 像素，不是 PUBG 原始鼠标输入；系统缩放、指针速度与加速都会影响结果。 因此三项测试只做最高 ±6% 的相对微调，cm/360 仍由你填写的 DPI 与 PUBG 数值估算，最终请在训练场用尺复核。
